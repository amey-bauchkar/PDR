### 3.1 Remote Fiber Monitoring System (RFMS)
- **Survivability:** Continuous corridor visibility. Detects cable cuts, macro-bends, and optical degradation instantly.
- **Switch Latency:** Automated optical path switching in `< 10ms`.
- **Diagnostics:** Integrated live OTDR analytics pinpointing fault distances to within 1 meter with GIS mapping overlays.
- **Protocols:** Direct SCADA, NMS, and SNMP NOC telemetry.

### 3.2 Distributed Acoustic Sensing (DAS)
- Converts standard single-mode optical fiber cables into continuous virtual acoustic/seismic sensor arrays.
- **Range:** 50 km+ per interrogator channel.
- **Spatial Resolution:** $\pm 5\text{ m}$.
- **Pattern Classification:** AI/ML neural networks distinguish foot traffic, heavy vehicles, manual digging, and pipeline leaks.

### 3.3 Distributed Temperature Sensing (DTS)
- Uses Raman scattering to profile temperature continuously along optical fiber links.
- **Accuracy:** $\pm 1^\circ\text{C}$ sensitivity.
- **Acquisition Speed:** $< 10\text{ s}$ per scan.
- **Use Cases:** Thermal overload detection in high-voltage underground cables, subsea cables, oil & gas pipelines, and subway tunnels.

### 3.4 Tactical Optical Fiber Drone Communication Kit
- Ultra-lightweight tethered and spool-deployed optical fiber communication system for Unmanned Aerial Vehicles (UAVs / FPV drones).
- **Immunity:** 100% immune to RF jamming, EW (Electronic Warfare), and spoofing.
- **Components:**
  1. *UAV Fiber Optic Spool:* High-tensile, micro-diameter buffered optical fiber spool deploying seamlessly during flight (up to 20km+).
  2. *Sky Unit (FPV Optical Terminal):* Ultra-compact optical transceiver mounted on the drone.
  3. *Ground Station Unit:* Ruggedized optical receiver converting high-throughput video/telemetry to Ethernet/HDMI.

## 5. PDR 5-Segment Ordering Code System & Part Number Logic

PDR uses a standardized, deterministic 5-segment part numbering system for all optical cable assemblies:

$$\mathbf{[Assembly]} - \mathbf{[End\#1\ Connector]} - \mathbf{[End\#2\ Connector]} - \mathbf{[Cable\ Construction]} - \mathbf{[Length\ Code]}$$

```
 Example Part Number: S1-L6-C2-01-0030
  │   │  │  │   └── Length Code: 0030 = 3.0 meters (30 x 0.1m)
  │   │  │  └────── Cable Construction: 01 = Simplex 3.0mm Jacket
  │   │  └───────── End #2 Connector: C2 = SC/UPC
```

### 5.4 Segment 5: Length Code Formula
Length code is an exact 4-digit number calculated as:
$$\text{Code} = \text{round}(\text{Length in Meters} \times 10)$$
- `0005` $\rightarrow 0.5\text{ m}$
- `0010` $\rightarrow 1.0\text{ m}$
- `0020` $\rightarrow 2.0\text{ m}$
- `0030` $\rightarrow 3.0\text{ m}$
- `0050` $\rightarrow 5.0\text{ m}$
- `0100` $\rightarrow 10.0\text{ m}$
- `0300` $\rightarrow 30.0\text{ m}$
- `0500` $\rightarrow 50.0\text{ m}$
- `1000` $\rightarrow 100.0\text{ m}$
- `9990` $\rightarrow 999.0\text{ m}$

Engineered as a high-precision backend service and frontend calculator:
- **Formula:**

- **Signal Quality Grading:**
  - $\text{Loss} \le 10.0\text{ dB} \implies$ **EXCELLENT** (Optimized for maximum throughput)

  - $\text{Loss} > 20.0\text{ dB} \implies$ **POOR** (Exceeds safe receiver sensitivity thresholds)

### 8.1 Database Schema (PostgreSQL DDL)
The system runs on 12 relational tables:
1. `product_categories`: Category slug, name, description, sort order, and SHA-256 hash keys.
2. `catalog_sections`: High-level catalog navigation sections (`active`, `passive`, `cable`, `test`, `specialty`, `tools`).
3. `catalog_groups`: Sub-category groupings within sections (e.g. SFP Transceivers, Cable Assemblies).
4. `catalog_products`: Core product entity with slug, title, description, image URL, datasheet URL, canonical URL, and status (`Active`, `Draft`, `Archived`).
5. `catalog_product_features`: Normalized 1-to-many product feature bullets.
6. `catalog_product_applications`: Normalized 1-to-many target application points.
7. `catalog_product_specs`: Key-value pairs for technical specifications (e.g. Insertion Loss, Operating Temperature).
8. `catalog_product_relations`: Cross-product recommendations and accessory relations.
9. `quote_sessions`: Active user shopping carts with session hashes and live totals.
10. `quote_session_items`: Itemized lines within active quote sessions.
11. `quote_requests`: Submitted RFQ submissions with buyer details, company, notes, and status.
12. `quote_request_items`: Ordered products and configurations linked to submitted RFQs.
13. `contact_inquiries`: General engineering and distributor inquiries submitted via `/contact`.
